# Change Log

## 0.1.0

Initial release.

- Language Model Chat Provider (`nobugsgiven-kimi`) surfacing **Kimi K3**, **Kimi K2.6** and **Kimi K2.5** in the Copilot Chat model picker.
- Streaming chat via Moonshot's OpenAI-compatible API with full tool-call lifecycle (Agent mode), image input, and cancellation support.
- API key management in VS Code Secret Storage: `Kimi: Set API Key`, `Kimi: Manage API Key`, `Kimi: Reset API Key`, `Kimi: Test API Connection`.
- Advanced `kimi.apiBaseUrl` endpoint setting and opt-in sanitized diagnostics (`kimi.diagnostics`).
- One-time first-install welcome.
